# Propositional Theory: PROV-O Section 3.1

A formalization of the commitments and accepted material implications from the dialectical examination of PROV-O Section 3.1.

## Signature

### Sorts

```
E : Entity
A : Activity
G : Agent
T : Time
C : Context
```

### Predicates (PROV-O Relations)

```
used(A, E)                    — Activity A used Entity E
wasGeneratedBy(E, A)          — Entity E was generated by Activity A
wasInformedBy(A₁, A₂)         — Activity A₁ was informed by Activity A₂
wasDerivedFrom(E₁, E₂)        — Entity E₁ was derived from Entity E₂
wasAssociatedWith(A, G)       — Activity A was associated with Agent G
wasAttributedTo(E, G)         — Entity E was attributed to Agent G
actedOnBehalfOf(G₁, G₂)       — Agent G₁ acted on behalf of Agent G₂
specializationOf(E₁, E₂)      — Entity E₁ is a specialization of Entity E₂
alternateOf(E₁, E₂)           — Entity E₁ is an alternate of Entity E₂
```

### Auxiliary Predicates

```
responsibleFor(G, X)          — Agent G bears responsibility for X
primaryResponsibility(G, X)   — Agent G has primary responsibility for X
secondaryResponsibility(G, X) — Agent G has secondary responsibility for X
durational(A)                 — Activity A has temporal extent
modeledAsAgent(X, C)          — X is modeled as an Agent in context C
sameUnderlying(E₁, E₂)        — E₁ and E₂ describe the same underlying thing
```

```

A1.3  ∀a. Activity(a) → durational(a)
```

## Material Implications (Accepted Inferences)

### M1. Generation-Use to wasInformedBy (Commitment #30)

```
M1.1  ∀a₁,a₂. (∃e. wasGeneratedBy(e, a₂) ∧ used(a₁, e)) → wasInformedBy(a₁, a₂)
```

**Non-implication (explicit):**
```
M1.2  ¬(∀a₁,a₂. wasInformedBy(a₁, a₂) → ∃e. wasGeneratedBy(e, a₂) ∧ used(a₁, e))
```

*wasInformedBy does not entail the existence of an intermediate Entity.*

### M2. Generation-Use to wasDerivedFrom (Commitment #24)

**Non-implication (explicit):**
```
M2.1  ¬(∀e₁,e₂. (∃a. used(a, e₂) ∧ wasGeneratedBy(e₁, a)) → wasDerivedFrom(e₁, e₂))
```

*wasDerivedFrom requires explicit assertion; it is not entailed by generation-use chains.*

### M3. Delegation Hierarchy (Commitment #25)

```
M3.1  ∀g₁,g₂,x. actedOnBehalfOf(g₁, g₂) ∧ responsibleFor(g₁, x) →
        primaryResponsibility(g₂, x) ∧ secondaryResponsibility(g₁, x)
```

### M4. Delegation Transitivity (Commitment #26)

```
M4.1  ∀g₁,g₂,g₃. actedOnBehalfOf(g₁, g₂) ∧ actedOnBehalfOf(g₂, g₃) →
        actedOnBehalfOf(g₁, g₃)
```

### M5. Expanded Terms Properties (Commitment #23)

**alternateOf is an equivalence relation:**
```
M5.1  ∀e. alternateOf(e, e)                                           — reflexive
M5.2  ∀e₁,e₂. alternateOf(e₁, e₂) → alternateOf(e₂, e₁)               — symmetric
M5.3  ∀e₁,e₂,e₃. alternateOf(e₁, e₂) ∧ alternateOf(e₂, e₃) →
        alternateOf(e₁, e₃)                                            — transitive
```

**specializationOf is a strict partial order with inheritance:**
```
M5.4  ∀e. ¬specializationOf(e, e)                                      — irreflexive
M5.5  ∀e₁,e₂,e₃. specializationOf(e₁, e₂) ∧ specializationOf(e₂, e₃) →
        specializationOf(e₁, e₃)                                       — transitive
M5.6  ∀e₁,e₂. specializationOf(e₁, e₂) →
        ∀P. hasAttribute(e₂, P) → hasAttribute(e₁, P)                  — inheritance
```

**specializationOf entails alternateOf:**
```
M5.7  ∀e₁,e₂. specializationOf(e₁, e₂) → alternateOf(e₁, e₂)
```

**wasDerivedFrom is NOT transitive (explicit non-implication):**
```
M5.8  ¬(∀e₁,e₂,e₃. wasDerivedFrom(e₁, e₂) ∧ wasDerivedFrom(e₂, e₃) →
        wasDerivedFrom(e₁, e₃))
```

### M6. Derivation Subtypes (Commitment #28)

```
M6.1  ∀e₁,e₂. Revision(e₁, e₂) → wasDerivedFrom(e₁, e₂)
M6.2  ∀e₁,e₂. Quotation(e₁, e₂) → wasDerivedFrom(e₁, e₂)
M6.3  ∀e₁,e₂. PrimarySource(e₁, e₂) → wasDerivedFrom(e₁, e₂)
```

## Pragmatist Metatheory

The following are not object-level propositions but metatheoretic commitments about how the theory is to be interpreted.

### P1. Context-Relative Entity Individuation (Commitment #18)

```
For any context C:
  What counts as "the same Entity" is determined by C.
  hasFixedAspects(e) is relative to the provenance description, not metaphysically absolute.
```

**Corollary:** Change is modeled via derivation:
```
If e₁ and e₂ represent "the same thing" at different times:
  e₁ ≠ e₂ (numerically distinct Entities)
  wasDerivedFrom(e₂, e₁) (related by derivation)
```

### P2. Context-Relative Agent Ascription (Commitment #29)

```
For any causal chain χ and contexts C₁, C₂:
  modeledAsAgent(x, C₁) ∧ modeledAsAgent(y, C₂)
  is consistent even when x ≠ y and χ is the same underlying causal process.
```

**Example:**
```
  modeledAsAgent(Organization, LegalContext)
  modeledAsAgent(Script, DebuggingContext)
  modeledAsAgent(Server, InfrastructureContext)
```

All may describe the same causal chain.

### P3. Shortcut Relations Are Genuinely Weaker (Commitments #24, #30)

```
The relations wasInformedBy and wasDerivedFrom are:
  - Inferable FROM more detailed chains (M1.1)
  - NOT reducible TO those chains (M1.2, M2.1)

They make weaker ontological commitments than their expansions.
```

## Consistency Notes

### Avoided Tensions

The following potential tensions were examined and resolved without requiring denial:

1. **Pragmatist individuation vs. fixed aspects**: Resolved by interpreting "fixed" as context-relative (#18)

2. **Agency vs. causation**: Resolved by pragmatist reading of "responsibility" (#29)

3. **Shortcut sufficiency vs. chain entailment**: Resolved by asymmetric inference (#24, #30)

4. **wasDerivedFrom vs. Expanded Terms**: Resolved by recognizing distinct formal properties (#23)

### Retracted Position

```
RETRACTED: wasDerivedFrom suffices for cross-context Entity identity
REASON: Expanded Terms have formal properties (transitivity, attribute inheritance)
        that wasDerivedFrom cannot express
```
